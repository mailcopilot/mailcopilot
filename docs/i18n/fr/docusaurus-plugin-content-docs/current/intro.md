# Bienvenue dans MailCopilot

:::info Beta
MailCopilot est actuellement en **Beta**. Les fonctionnalites principales sont stables et pretes pour une utilisation quotidienne, mais vous pourriez rencontrer quelques imperfections. Vos retours sont les bienvenus !
:::

MailCopilot est un client de messagerie de bureau AI-native, concu pour la rapidite, la confidentialite et la simplicite. Il se connecte a vos comptes de messagerie existants via les protocoles standard IMAP/SMTP et garde vos donnees sous votre controle. Grace a un assistant IA integre au coeur de l'application, MailCopilot vous aide a lire, ecrire et gerer vos e-mails plus rapidement que jamais.

## Fonctionnalites principales

- **Comptes multiples** -- connectez plusieurs comptes de messagerie et basculez entre eux instantanement, ou utilisez la boite de reception unifiee pour voir tous les messages au meme endroit.
- **Interface native rapide** -- construit avec Electron et React, avec des themes clair et sombre.
- **Confidentialite avant tout** -- les e-mails sont affiches dans un bac a sable securise, les images externes sont bloquees par defaut. Les mots de passe sont stockes dans le trousseau systeme.
- **Regroupement en fils** -- les messages lies sont automatiquement regroupes en fils de discussion.
- **Assistant IA (optionnel)** -- un assistant integre propulse par Claude peut resumer les e-mails, rediger des reponses et vous aider a gerer votre boite de reception.
- **Raccourcis clavier** -- preselections de raccourcis style Gmail et Outlook pour naviguer et agir sans souris.
- **Envoi programme** -- redigez un message maintenant et programmez son envoi pour plus tard.
- **Mode hors ligne** -- telechargez les messages pour les lire sans connexion internet.
- **Glisser-deposer** -- deplacez les messages entre les dossiers par glisser-deposer.
- **Notifications de bureau** -- recevez des notifications pour les nouveaux e-mails.
- **6 langues d'interface** -- anglais, russe, francais, allemand, espagnol et italien.

## Plateformes prises en charge

MailCopilot est disponible pour **Linux** (AppImage, deb, rpm) et **Windows** (installateur). Une version macOS est prevue pour une prochaine version.
