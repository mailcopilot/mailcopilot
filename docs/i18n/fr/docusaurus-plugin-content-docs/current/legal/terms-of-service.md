## 2. Description de l'Application

MailCopilot est un client de messagerie de bureau pour Windows, macOS et Linux qui vous permet de :

- Connecter des comptes de messagerie via les protocoles IMAP/SMTP.
- Lire, rédiger, envoyer et organiser vos e-mails.
- Gérer plusieurs comptes de messagerie.
- Utiliser un assistant IA optionnel pour vous aider dans vos tâches de messagerie.
