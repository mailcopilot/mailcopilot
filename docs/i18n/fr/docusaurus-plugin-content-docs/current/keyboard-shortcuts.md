# Raccourcis clavier

Appuyez sur **?** dans l'application pour afficher la reference. Preselection **Gmail** par defaut.

## Navigation

| Raccourci | Action |
|-----------|--------|
| **j** / **k** | Message suivant / precedent |
| **o** ou **Enter** | Ouvrir le message |
| **u** | Retour a la liste |
| **/** | Focus sur la recherche |
| **g** puis **i** | Boite de reception |
| **g** puis **s** | Envoyes |
| **g** puis **d** | Brouillons |
| **g** puis __*__ | Etoiles |
| **g** puis **r** | Aller à « Lire plus tard » |

## Actions

| Raccourci | Action |
|-----------|--------|
| **c** | Rediger |
| **r** | Repondre |
| **a** | Repondre a tous |
| **f** | Transferer |
| **s** | Etoiler |
| **e** | Archiver |
| **Shift+I** | Marquer comme lu |
| **Shift+U** | Marquer comme non lu |
| **!** | Spam |
| **x** | Selectionner |
| **v** | Deplacer |
| **z** | Annuler |
| **#** ou **Delete** | Supprimer |
| **Escape** | Effacer la selection |
| **p** | Épingler / désépingler le message |
| **Ctrl+P** | Imprimer le message |

## IA

| Raccourci | Action |
|-----------|--------|
| **Ctrl+Shift+S** | Resume rapide IA |

## Menu contextuel

Faites un clic droit sur n'importe quel message de la liste pour ouvrir son menu contextuel. Le menu contextuel donne accès aux actions rapides (répondre, archiver, déplacer, etc.) sans ouvrir le message.

## General

| Raccourci | Action |
|-----------|--------|
| **Ctrl+K** | Palette de commandes (accès rapide aux dossiers : Boite de reception, En veille, Suivis, Lire plus tard, etc.) |
| **?** | Afficher les raccourcis |
