# Dossiers

## Navigation

Cliquez sur un dossier dans la barre laterale pour voir ses messages. Raccourcis : **g** puis **i** (Boite de reception), **g** puis **s** (Envoyes), **g** puis **d** (Brouillons), **g** puis __*__ (Etoiles), **g** puis **r** (Lire plus tard).

## Dossiers speciaux

| Dossier | Description |
|---------|-------------|
| **Boite de reception** | Messages recus. |
| **Envoyes** | Messages envoyes. |
| **Brouillons** | Brouillons non envoyes. |
| **Corbeille** | Messages supprimes. |
| **Spam** | Messages marques comme spam. |
| **Archive** | Messages archives. |
| **Boite d'envoi** | Messages programmes. |
| **En veille** | Messages mis en veille. Ils reapparaitront a l'expiration du delai de mise en veille. |
| **Suivis** | Emails avec des rappels de suivi en attente de réponse. |
| **Lire plus tard** | Emails marqués pour lecture ultérieure. Contrairement aux reportés, ils restent dans leur dossier d'origine. |

## Deplacer des messages

Glisser-deposer, menu contextuel (clic droit > **Deplacer vers un dossier**), raccourci **v**, ou boutons d'action.

## Menu contextuel du dossier

Clic droit sur un dossier dans la barre latérale pour accéder aux options :

- **Synchroniser tous les en-têtes** / **Synchroniser à l'ouverture** -- contrôle la synchronisation des en-têtes.
- **Inclure dans la recherche** / **Exclure de la recherche** -- active ou désactive l'indexation du corps des messages pour la recherche en texte intégral (`body:`). Désactivé par défaut pour les dossiers Indésirables, Spam et Corbeille.
- **Afficher/Masquer dans les badges de non-lus** -- inclure ou non dans le badge total.
- **Afficher/Masquer dans la barre latérale** -- contrôle la visibilité.
- **Changer l'icône** -- définir une icône ou un emoji personnalisé.
- **Renommer le dossier** -- renommer sur le serveur.
- **Supprimer le dossier** -- supprimer du serveur (confirmation requise).

## Badges de non-lus

Chaque dossier affiche un badge indiquant le nombre de messages non lus. Les messages mis en veille sont automatiquement exclus de ces compteurs — ils ne gonfleront pas vos badges de non-lus tant qu'ils sont en veille.

## Suppression definitive

La suppression depuis la Corbeille est definitive. Un dialogue de confirmation apparait avant la suppression.
