# Atajos de teclado

Pulsa **?** para ver la referencia. Preset por defecto: **Gmail**.

## Navegacion

| Atajo | Accion |
|-------|--------|
| **j** / **k** | Mensaje siguiente / anterior |
| **o** o **Enter** | Abrir mensaje |
| **u** | Volver a la lista |
| **/** | Enfocar busqueda |
| **g** luego **i** | Bandeja de entrada |
| **g** luego **s** | Enviados |
| **g** luego **d** | Borradores |
| **g** luego __*__ | Destacados |
| **g** y luego **r** | Ir a «Leer más tarde» |

## Acciones

| Atajo | Accion |
|-------|--------|
| **c** | Redactar |
| **r** | Responder |
| **a** | Responder a todos |
| **f** | Reenviar |
| **s** | Destacar |
| **e** | Archivar |
| **Shift+I** | Marcar como leido |
| **Shift+U** | Marcar como no leido |
| **!** | Spam |
| **x** | Seleccionar |
| **v** | Mover |
| **z** | Deshacer |
| **#** o **Delete** | Eliminar |
| **Escape** | Limpiar seleccion |
| **p** | Fijar / desfijar mensaje |
| **Ctrl+P** | Imprimir mensaje |

## IA

| Atajo | Accion |
|-------|--------|
| **Ctrl+Shift+S** | Resumen rapido IA |

## Menu contextual

Haz clic derecho sobre cualquier mensaje de la lista para abrir su menu contextual. El menu contextual ofrece acciones rapidas (responder, archivar, mover y mas) sin necesidad de abrir el mensaje.

## General

| Atajo | Accion |
|-------|--------|
| **Ctrl+K** | Paleta de comandos (incluye navegación a Pospuestos, Seguimiento y Leer más tarde) |
| **?** | Mostrar atajos |
