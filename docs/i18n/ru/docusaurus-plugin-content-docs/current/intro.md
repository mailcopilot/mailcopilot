# Добро пожаловать в MailCopilot

:::info Бета
MailCopilot находится в стадии **Бета**. Основные функции стабильны и готовы к повседневному использованию, но вы можете столкнуться с отдельными недочётами. Мы будем рады вашим отзывам!
:::

MailCopilot -- это AI-native настольный почтовый клиент, созданный для скорости, конфиденциальности и простоты. Он подключается к вашим почтовым аккаунтам через стандартные протоколы IMAP/SMTP и сохраняет ваши данные под вашим контролем. Благодаря встроенному AI-ассистенту в основе, MailCopilot помогает читать, писать и управлять почтой быстрее, чем когда-либо.

## Основные возможности

- **Несколько аккаунтов** -- подключите несколько почтовых аккаунтов и переключайтесь между ними мгновенно, или используйте единый почтовый ящик для просмотра всей почты в одном месте.
- **Быстрый нативный интерфейс** -- построен на Electron и React, с поддержкой светлой и тёмной тем.
- **Приватность на первом месте** -- письма отображаются в безопасной песочнице, внешние изображения блокируются по умолчанию. Пароли хранятся в системной связке ключей.
- **Группировка в цепочки** -- связанные сообщения автоматически группируются в цепочки для удобного чтения.
- **AI-ассистент (опционально)** -- встроенный ассистент на базе Claude может резюмировать письма, составлять черновики ответов и помогать управлять входящими.
- **Горячие клавиши** -- пресеты горячих клавиш в стиле Gmail и Outlook для навигации и действий без мыши.
- **Отложенная отправка** -- напишите письмо сейчас и запланируйте отправку на позже, на завтрашнее утро или на выбранное время.
- **Офлайн-режим** -- загружайте письма для чтения без интернета.
- **Перетаскивание** -- перемещайте письма между папками перетаскиванием в боковой панели.
- **Уведомления на рабочем столе** -- получайте уведомления о новой почте, даже когда окно свёрнуто.
- **6 языков интерфейса** -- английский, русский, французский, немецкий, испанский и итальянский.

## Поддерживаемые платформы

MailCopilot доступен для **Linux** (AppImage, deb, rpm) и **Windows** (установщик). Версия для macOS запланирована в будущих выпусках.
