# Фото отправителей (Gravatar)

Параметр **Показывать фото отправителей (Gravatar)** на новых установках выключен. Пока он выключен, MailCopilot не отправляет запросов на gravatar.com.

Установка, обновлённая с версии до 1.27.2, сохраняет прежнюю настройку. Старые версии включали параметр по умолчанию и записывали это значение в настройки, поэтому у большинства существующих установок он включён. Если фото не нужны, выключите параметр, как описано ниже.

## Что передаётся при включённом параметре

Для каждого адреса отправителя, показанного в списке писем, приложение запрашивает фото на `www.gravatar.com`. Запрос идёт напрямую с вашего компьютера на Gravatar. Серверы MailCopilot в нём не участвуют, и через прокси для внешних изображений в письмах он не проходит.

Gravatar получает:

- SHA-256 хеш адреса отправителя (без пробелов, в нижнем регистре). Зная адрес, любой может вычислить его хеш и сопоставить с запросом;
- ваш IP-адрес и время запроса;
- обычные заголовки браузерного запроса, в том числе User-Agent с названием и версией приложения.

Заголовка Referer в запросе нет. Текст писем и темы Gravatar не получает. Адреса ваших аккаунтов и профилей отправителя в списке писем пропускаются, их хеши оттуда не отправляются.

В памяти приложение запоминает, у каких отправителей нет фото. Фото, которые вернул Gravatar, также сохраняются в HTTP-кэше Chromium в папке данных приложения на диске, как любое изображение, загружаемое приложением. Выключение параметра этот кэш не очищает.

## Где изменить

Настройки > Продуктивность > **Показывать фото отправителей (Gravatar)**.

## Аватар вашего аккаунта

Режим аватара **Gravatar** для аккаунта (Настройки > Аккаунты) выбирается отдельно. При его выборе такой же запрос делается для адреса этого аккаунта. Другие режимы запросов не делают.
