# Папки

## Навигация по папкам

Почтовые папки отображаются в боковой панели. Нажмите на папку, чтобы увидеть её письма. Специальные папки расположены вверху, далее идут пользовательские папки в алфавитном порядке.

Быстрый переход по горячим клавишам:
- **g** затем **i** -- Входящие
- **g** затем **s** -- Отправленные
- **g** затем **d** -- Черновики
- **g** затем __*__ -- Помеченные
- **g**, затем **r** — перейти к папке «Прочитать позже»

## Специальные папки

| Папка | Описание |
|-------|----------|
| **Входящие** | Входящие сообщения. |
| **Отправленные** | Отправленные вами письма. |
| **Черновики** | Неотправленные черновики. |
| **Корзина** | Удалённые письма. Отсюда можно удалить навсегда. |
| **Спам** | Письма, помеченные как спам. |
| **Архив** | Архивированные письма. |
| **Исходящие** | Письма, запланированные к отправке. |
| **Отложенные** | Отложенные письма. Они вернутся, когда наступит указанное время. |
| **Напоминания** | Письма с установленными напоминаниями о необходимости ответа. |
| **Прочитать позже** | Письма, отмеченные для чтения позже. В отличие от отложенных, они остаются в исходной папке. |

MailCopilot автоматически определяет, какая серверная папка соответствует каждой роли. Вы можете изменить маппинг в **Настройки > Папки**.

## Перемещение писем между папками

Несколько способов:

- **Перетаскивание** -- перетащите письмо из списка на папку в боковой панели.
- **Контекстное меню** -- нажмите правой кнопкой и выберите **Переместить в папку**.
- **Горячая клавиша** -- нажмите **v** для выбора папки.
- **Кнопки действий** -- используйте кнопки «Удалить», «Архивировать» и «Спам».

## Контекстное меню папки

Нажмите правой кнопкой на папку в боковой панели:

- **Синхронизировать все заголовки** / **Синхронизировать при открытии** -- управляют синхронизацией заголовков папки.
- **Включить в поиск** / **Исключить из поиска** -- переключить индексацию тел писем для полнотекстового поиска (`body:`). По умолчанию для папок «Нежелательная почта», «Спам» и «Корзина» отключено.
- **Показать/Скрыть в бейджах непрочитанных**.
- **Показать/Скрыть в боковой панели**.
- **Изменить иконку** -- задать пользовательскую эмодзи.
- **Переименовать папку**.
- **Удалить папку** (с подтверждением).

## Бейджи непрочитанных

Каждая папка показывает бейдж с количеством непрочитанных. Отложенные письма автоматически исключаются из этих счётчиков — пока письмо отложено, оно не увеличивает бейдж непрочитанных. Настройте, какие папки показывают бейджи, через контекстное меню или в **Настройки > Папки**.

## Безвозвратное удаление

При удалении письма из Корзины оно удаляется навсегда. Диалог подтверждения появится перед удалением, так как это действие необратимо.
