# Поиск

MailCopilot предоставляет мощные возможности поиска, которые помогут найти любое письмо во всех аккаунтах и папках.

## Простой поиск

Введите текст в строку поиска вверху списка писем. Результаты появляются мгновенно по мере ввода.

## Область поиска

При поиске вы можете выбрать область с помощью переключателей под строкой поиска:

- **Текущая папка** — поиск только в текущей папке.
- **Все папки** — поиск по всем папкам текущего аккаунта.
- **Все аккаунты** — поиск по всем подключённым аккаунтам и папкам.

## Операторы поиска

Используйте операторы для точного поиска:

| Оператор | Описание | Пример |
|----------|---------|--------|
| `from:` | По отправителю | `from:alice@example.com` |
| `to:` | По получателю | `to:bob@example.com` |
| `subject:` | По теме | `subject:встреча` |
| `body:` | По тексту письма | `body:счёт` |
| `filename:` | По имени вложения | `filename:отчёт.pdf` |
| `is:unread` | Непрочитанные | `is:unread` |
| `is:starred` | С флагом | `is:starred` |
| `has:attachment` | С вложениями | `has:attachment` |
| `before:` | До даты | `before:2026-01-01` |
| `after:` | После даты | `after:2025-12-01` |

Комбинируйте операторы со свободным текстом: `from:alice subject:отчёт is:unread`.

Используйте `-` для исключения: `-from:spam@example.com`.

## Полнота поиска

MailCopilot ищет в локальном кэше писем. Индикатор полноты под строкой поиска показывает:

- **Покрытие заголовков** — сколько папок синхронизировано (например, «Заголовки: 5/8 папок»).
- **Индексация текста** — процент писем с проиндексированным текстом для поиска `body:`.

Стандартные папки (Входящие, Отправленные, Архив, Черновики) индексируются полностью по умолчанию. Папки «Нежелательная почта», «Спам» и «Корзина» исключены из полнотекстовой индексации по умолчанию, чтобы результаты поиска оставались чистыми и снизить использование диска. Изменить настройку индексации для любой папки можно через контекстное меню (правая кнопка в боковой панели) или в **Настройки > Папки**.

Письмо, которое открылось как обычно — включая письмо, чьё тело было обрезано [мягким пределом в 1 МБ](../usage/reading-emails#очень-большие-письма) — сразу же доступно для поиска по `body:`, как и любое другое письмо: индексируются первые примерно 200 000 символов тела. Письмо, превысившее жёсткий предел в 100 МБ (см. тот же раздел), — другое дело: поскольку его тело не декодировалось при открытии, поиск по `body:` начинает находить его только после того, как фоновый индексатор тел заберёт и проиндексирует его с сервера, а это может занять больше времени, чем для обычного письма.

## Серверный поиск

При поиске в конкретной папке MailCopilot может также запрашивать IMAP-сервер для поиска писем, ещё не попавших в локальный кэш. Серверные результаты отмечаются значком «+N с сервера».

Серверный поиск поддерживает базовые операторы (`from:`, `to:`, `subject:`, `before:`, `after:`), но не продвинутые (`body:`, `filename:`, `is:`, `has:`).

## Ранжирование по релевантности

Результаты поиска ранжируются по релевантности. Совпадения в теме письма ранжируются выше, чем совпадения в тексте.
