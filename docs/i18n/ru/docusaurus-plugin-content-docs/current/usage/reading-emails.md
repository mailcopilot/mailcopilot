# Чтение писем

## Просмотр сообщения

Нажмите на любое письмо в списке, чтобы открыть его в панели чтения. Тело письма отображается в безопасной песочнице, которая защищает вас от потенциально вредоносного содержимого.

Навигация по письмам с клавиатуры:
- **j** -- следующее письмо
- **k** -- предыдущее письмо
- **o** или **Enter** -- открыть письмо
- **u** -- вернуться к списку

## Заголовки получателей

В панели чтения над телом письма отображаются поля **To**, **Cc** и (для отправленных писем) **Bcc**. Если в одном из полей больше трёх адресов, MailCopilot сворачивает остальные: первые три имени показываются встроенно, за ними следует кнопка **+N ещё**, где N — количество скрытых адресов.

Нажмите **+N ещё**, чтобы развернуть полный список получателей в несколько строк. Нажмите кнопку ещё раз, чтобы свернуть обратно. Также можно нажать **Esc** в развёрнутом состоянии, чтобы свернуть список.

Наведите курсор на имя получателя — появится подсказка с полной строкой `Имя <email@host>`. Пользователи клавиатуры могут переходить по Tab к каждому получателю и кнопке **+N ещё**; нажатие **Enter** или **Пробела** на кнопке переключает развёрнутое состояние.

**Конфиденциальность Bcc:** строка Bcc отображается только для писем, отправленных вами. Для входящих писем она никогда не показывается, поэтому получатели Bcc входящих сообщений остаются скрытыми.

## Внешние изображения

Для защиты конфиденциальности MailCopilot по умолчанию блокирует внешние изображения в письмах. Когда в письме есть заблокированные изображения, вы увидите баннер:

> «Внешние изображения заблокированы для защиты конфиденциальности.»

Нажмите **Показать изображения**, чтобы загрузить их для конкретного письма. Если вы хотите всегда загружать изображения, включите **«Всегда загружать внешние изображения»** в **Настройки > Продуктивность**.

## Цитируемый текст

Когда вы получаете ответ или пересланное письмо, MailCopilot автоматически сворачивает историю цитирования, чтобы вы видели только новый текст. Процитированная часть скрыта за виджетом **Показать цитируемый текст** в нижней части тела письма.

Нажмите **Показать цитируемый текст**, чтобы развернуть полную историю прямо в письме. Сворачивание цитат работает **только для HTML-писем**: блоки `<blockquote>` верхнего уровня и вложенные сворачиваются каждый независимо с помощью нативного элемента `<details>`/`<summary>` — JavaScript не требуется. MailCopilot также распознаёт шаблоны атрибуции в стиле Outlook (`-----Original Message-----`, `On … wrote:`), если они непосредственно предшествуют блоку `<blockquote>`, и сворачивает эти строки вместе с соответствующим блоком цитаты.

В письмах в формате обычного текста история цитирования отображается как есть, без сворачивания. Это известное ограничение, которое запланировано к устранению в одном из будущих выпусков.

Если письмо не содержит цитируемого текста, виджет не отображается.

## Группировка в цепочки

Когда группировка включена (по умолчанию), связанные письма объединяются в цепочки. В списке писем рядом с темой цепочки из более чем одного письма отображается значок `+N` — это количество дополнительных писем в цепочке; при наведении курсора всплывает подсказка с итоговым числом. Нажмите на цепочку в списке писем, чтобы открыть её в панели чтения.

### Непрочитанный статус строки цепочки

Строка цепочки в списке писем выделяется жирным (как непрочитанная), если непрочитано **хотя бы одно** письмо цепочки из показанных сейчас в списке — а не только самое свежее. Так непрочитанное письмо, затерянное в середине переписки, никогда не остаётся невидимым в списке, даже если самое новое письмо этой же цепочки уже прочитано.

Нажатие на непрочитанную цепочку открывает **самое старое непрочитанное** письмо цепочки в качестве активной развёрнутой карточки. Если в цепочке уже все письма прочитаны, нажатие открывает головное письмо строки — при сортировке по дате, которая стоит по умолчанию, это самое новое письмо.

Такое открытие письма не помечает остальную часть цепочки как прочитанную. Пометка всех писем цепочки прочитанными остаётся отдельным явным действием — см. **Отметить тред прочитанным** в разделе [Действия с цепочкой](#действия-с-цепочкой) ниже.

### Просмотр цепочки — стопка карточек

Цепочки из двух и более писем отображаются в виде вертикальной стопки карточек. По умолчанию карточки расположены **от новых к старым**. Активной развёрнутой карточкой становится то письмо, которое было открыто, — самое старое непрочитанное, если в цепочке есть непрочитанные, либо головное письмо, если цепочка полностью прочитана; остальные письма остаются свёрнутыми.

- **Свёрнутые карточки** показывают аватар отправителя, имя отправителя, дату в удобном формате и короткий фрагмент текста. Если у письма нет текста для предпросмотра, карточка показывает **«(нет предпросмотра)»**.
- Нажмите на любую свёрнутую карточку, чтобы развернуть её. Нажмите на развёрнутую карточку повторно, чтобы свернуть её. В цепочке может быть развёрнута только одна карточка: открытие другого письма закрывает предыдущую.

Цепочки из одного письма и аккаунты с отключённой группировкой по-прежнему используют обычный просмотр одного письма — стопка карточек появляется только при наличии двух и более писем.

Включить или отключить группировку можно в **Настройки > Продуктивность > Группировать письма в цепочки**.

### Порядок писем в треде

По умолчанию самое новое письмо находится вверху стопки карточек, чтобы вы сразу видели последний ответ — так же, как новые письма появляются во входящих. Переключить порядок можно в **Настройки > Продуктивность > Порядок писем в треде**:

- **Сначала новые** (по умолчанию) — самое новое письмо находится вверху; более старые — ниже.
- **Сначала старые** — письма расположены в хронологическом порядке сверху вниз, самое новое письмо — внизу стопки.

Настройка применяется ко всем цепочкам в панели чтения и вступает в силу немедленно при изменении.

### Действия с цепочкой

При просмотре цепочки из двух и более писем единая панель инструментов в верхней части просмотрщика писем переходит в режим цепочки. Это та же самая панель, что используется и для одиночных писем, — её кнопки адаптируются к семантике цепочки:

- **Ответить** -- создать ответ отправителю последнего письма в цепочке.
- **Ответить всем** -- ответить всем участникам последнего письма, исключая основной адрес вашего аккаунта.
- **Переслать** -- переслать последнее письмо цепочки другому адресату.
- **Архивировать тред** -- перемещает всю цепочку в папку «Архив». Недоступно, если папка «Архив» не настроена.
- **Удалить тред** -- решается для каждой папки отдельно: письма, которые ещё можно переместить в «Корзину», перемещаются туда сразу же. Письма, которые уже находятся в «Корзине», или принадлежат аккаунту без папки «Корзина», вместо этого попадают под диалог подтверждения перед окончательным удалением. Если цепочка целиком лежит в одной папке, срабатывает только один из этих путей — как и раньше; если письма цепочки разбросаны по нескольким папкам (например, один ответ уже лежит в «Корзине», а остальная переписка — нет), может сработать сразу оба: перемещаемые письма перемещаются, а диалог подтверждения покрывает только то, что осталось.
- **Отметить тред прочитанным** -- помечает все письма в цепочке как прочитанные. Эта кнопка отображается только при наличии хотя бы одного непрочитанного письма; когда все письма прочитаны, кнопка скрыта.
- **Отложить** -- временно скрывает **всю цепочку** и возвращает все её письма в выбранное время. Диалог откладывания привязан к последнему письму, но откладываются все письма цепочки одновременно. Параметры — те же, что и для отдельных писем. В папке «Черновики» кнопка скрыта.
- **Спам** -- в режиме цепочки открывает диалог подтверждения с вопросом, отметить ли все письма цепочки как спам. Отменить пометку «спам» сложнее, чем архивацию, поэтому дополнительный запрос намеренный.
- **Пометить звёздочкой, Закрепить, Печать, Открыть в окне, Открыть в аккаунте** -- эти кнопки действуют на текущее активное (развёрнутое) письмо в цепочке, а не на всю цепочку.

Ответить, Ответить всем и Переслать относятся к последнему письму цепочки. Архивировать тред, Удалить тред, Отметить тред прочитанным и Отложить применяются ко всем письмам цепочки одновременно.

### AI-резюме цепочки

Когда вы открываете цепочку из **трёх и более писем** и AI-резюме цепочки включено для аккаунта, над стопкой карточек появляется краткое AI-резюме в одну строку. Нажмите на него, чтобы развернуть пять пунктов с ключевыми моментами переписки. Нажмите на строку резюме ещё раз, чтобы свернуть пункты.

AI-резюме цепочки **по умолчанию выключено** и включается **отдельно для каждого аккаунта** в **Настройки > AI > AI-резюме цепочки**. См. [AI-ассистент](../ai-assistant#ai-резюме-цепочки) — как включить эту функцию и что она отправляет вашему AI-провайдеру.

Более короткие цепочки (менее трёх писем) никогда не показывают полосу с резюме — стопка достаточно мала, чтобы прочитать её напрямую. Резюмируется только та цепочка, которую вы активно открыли; MailCopilot никогда не резюмирует цепочки в фоне или по всему почтовому ящику.

После того как цепочка была резюмирована, при повторном открытии резюме показывается мгновенно из кэша — MailCopilot не создаёт его заново, пока письма в цепочке не изменятся.

Если дневной AI-бюджет исчерпан, AI-провайдер не настроен или провайдер вернул временную ошибку, вместо резюме на полосе показывается пояснение причины. Кнопка **Повторить** появляется, если сбой был временной ошибкой провайдера.

### Быстрый ответ

Когда «Быстрый ответ» включён для аккаунта, на активно открытой карточке письма появляется кнопка **Быстрый ответ**. Нажмите её, чтобы AI подготовил два-три коротких варианта ответа на основе содержимого письма.

Нажмите на понравившийся вариант, чтобы открыть его в **новом окне написания письма**, предзаполненном этим текстом — ничего не отправляется автоматически, вы по-прежнему просматриваете и отправляете письмо сами.

«Быстрый ответ» **по умолчанию выключен** и включается **отдельно для каждого аккаунта** в **Настройки > AI > Быстрый ответ**. См. [AI-ассистент](../ai-assistant#быстрый-ответ) — как включить эту функцию и что она отправляет вашему AI-провайдеру.

## Перевод письма

MailCopilot умеет переводить открытое письмо на выбранный вами язык.

Перевод письма **по умолчанию выключен** и включается **отдельно для каждого аккаунта** в **Настройки > AI > Перевод писем ИИ** (включите «Разрешить перевод полученных писем и собственных черновиков через ИИ»). Та же настройка включает и [перевод черновика](../ai-assistant#перевод-черновика) в окне написания письма. См. [AI-ассистент](../ai-assistant#перевод-письма) — как включить эту функцию и что она отправляет вашему AI-провайдеру.

### Как использовать

Нажмите **Перевести** над телом письма, затем выберите язык из списка **Перевести на**. MailCopilot обращается к настроенному вами AI-провайдеру только в этот момент — автоматического перевода при открытии письма нет, поэтому просмотр письма на иностранном языке сам по себе никогда не тратит ваш AI-бюджет.

После появления перевода переключатель **Показать оригинал** / **Показать перевод** над телом письма позволяет в любой момент вернуться к исходному тексту и обратно. Само сохранённое письмо никогда не изменяется — перевод лишь показывается поверх него.

**HTML-письма переводятся по их текстовой версии.** Перевод всегда показывается обычным текстом, даже если исходное письмо в формате HTML — оформление, вёрстка и встроенные картинки не входят в перевод. Об этом прямо говорит подпись над переведённым текстом: «Перевод сделан по текстовой версии письма, поэтому оформление и картинки в него не вошли.»

### Определение языка оригинала

Перед переводом MailCopilot пытается определить исходный язык письма прямо на вашем компьютере и, если это удаётся, указывает его в подписи над переводом (например: «Машинный перевод с английского на русский. Оригинал — в одно нажатие.»). Определение происходит локально и служит только подписью — оно никогда не решает, можно ли перевести письмо.

Подпись можно исправить в любом случае, а не только когда определение не удалось. Если язык не удаётся определить достаточно уверенно, MailCopilot всё равно переводит письмо и просто не показывает подпись, предлагая выбор **Язык этого письма** (плейсхолдер: **Выберите язык**), чтобы указать его вручную. Если же подпись показана, но называет не тот язык — локальное определение может уверенно путать близкородственные языки, — рядом появляется ссылка **Это не тот язык?**, открывающая тот же выбор. В обоих случаях указание языка необязательно и лишь обновляет подпись у уже показанного перевода из кэша, не обращаясь к провайдеру повторно.

### Кэш переводов

Перевод письма на конкретный язык кэшируется локально на вашем устройстве по содержимому самого письма, целевому языку и версии контракта перевода (провайдер, модель и форма промпта), под которой он был получен — при повторном открытии того же письма и выборе того же языка используется кэшированный перевод вместо повторного обращения к провайдеру, а последующее изменение того, как MailCopilot формирует переводы, попадает под новый ключ, а не выдаёт результат старого контракта за актуальный. У кэша по-прежнему нет отдельного срока годности — вместо него запись стареет через лимит ниже. Каждый аккаунт хранит 500 последних переводов; при достижении этого предела самые старые переводы этого аккаунта удаляются, освобождая место для новых. Удаление аккаунта удаляет и его кэшированные переводы.

### Если перевод недоступен

MailCopilot называет конкретную причину, по которой перевод не удался, а не показывает общую ошибку:

- Перевод выключен для этого аккаунта.
- AI-провайдер ещё не настроен.
- AI-провайдер не вернул перевод и не объяснил причину.
- Перевод не поместился в предел ответа AI-провайдера, поэтому пришёл обрезанным и не показан.
- Текст этого письма ещё не загружен.
- Письмо слишком длинное, чтобы перевести его за один раз, а перевести только часть письма нельзя — в предел считается всё письмо целиком, включая переписку, которая может быть процитирована внутри него.
- AI-бюджет на этот период исчерпан.

**Кнопка «Попробовать ещё раз» появляется только там, где повтор действительно может изменить результат.** Каждое нажатие — это отдельный запрос, оплаченный вашему AI-провайдеру, поэтому MailCopilot не предлагает эту кнопку для отказа, который повторится один в один: перевод упёрся в предел ответа провайдера, письмо слишком длинное для перевода вообще, или перевод выключен для этого аккаунта. Для остальных причин — провайдер отказал без объяснения, письмо ещё загружается, провайдер не настроен, бюджет исчерпан — кнопка **Попробовать ещё раз** показывается, поскольку устранение причины (или просто ожидание) может дать успех при следующей попытке. Начиная со второй попытки, рядом с отказом появляется подпись **«Попытка 2»** (и далее по счёту), чтобы повтор, ничего не изменивший на экране, не выглядел как нажатие, которое не сработало.

## Работа с вложениями

Когда активное письмо содержит вложения, они отображаются над телом письма. У каждого вложения отображается:

- **Иконка типа файла** — выбирается по MIME-типу с откатом на расширение имени файла, когда MIME отсутствует, общий (`application/octet-stream`) или нераспознан: PDF, изображение, архив, документ, таблица, презентация, обычный текст, вложенное `.eml`-сообщение или общая иконка файла, если ничего более конкретного не подходит.
- **Имя файла**.
- **Размер файла**.

Изображения вёрстки, которые тело письма уже отображает встроенными — например, логотип в HTML-подписи, — никогда не убираются из списка. MailCopilot не может надёжно определить извне браузера, действительно ли та или иная часть оказалась видна на экране — это решают вёрстка, CSS и выбор варианта в адаптивном изображении, — поэтому вместо угадывания все части остаются достижимыми: настоящие вложения (файлы, реально прикреплённые отправителем) показываются первыми, а встроенные в письмо изображения переносятся в конец списка, за тот же переключатель раскрытия, что описан ниже.

Переключатель раскрытия появляется всякий раз, когда показать нужно больше, чем помещается свёрнуто, — если настоящих вложений больше четырёх, или если есть отложенные встроенные изображения, даже когда настоящих вложений четыре или меньше. Нажмите **Показать ещё (N)**, где N — только те элементы, что сейчас не видны, чтобы раскрыть всё, и **Свернуть**, чтобы снова свернуть список.

Нажмите кнопку скачивания в строке вложения, чтобы сохранить файл на компьютер. У кнопки скачивания заданo явное доступное (accessible) имя — так что программа экранного доступа объявит действие вместе с именем файла.

## Ссылки в письмах

При нажатии на ссылку в письме MailCopilot проверяет её безопасность:

- **Несовпадение ссылок** -- если текст ссылки показывает один домен, а фактическая ссылка ведёт на другой.
- **HTTP-ссылки** -- незашифрованные ссылки вызывают предупреждение.
- **IDN/Punycode-домены** -- домены с интернационализированными символами отмечаются.

Для подозрительных ссылок появляется диалог подтверждения, где вы можете увидеть реальный адрес назначения.

### Правая кнопка мыши на ссылке

Щёлкните правой кнопкой мыши по ссылке в теле письма, чтобы открыть небольшое контекстное меню с пунктами:

- **Открыть ссылку в браузере** -- открывает ссылку так же, как обычный клик по ней, включая описанные выше проверки безопасности (предупреждения о несовпадении домена и об HTTP, отметку IDN/punycode-доменов). Этот пункт появляется только в главном окне и в отдельном окне сообщения (см. [Открыть в окне](#открыть-в-окне)) — в окнах настроек, создания письма и учётной записи он не предлагается, поскольку в них ссылки из писем не отображаются.
- **Копировать адрес ссылки** -- копирует в буфер обмена реальный адрес назначения ссылки, а не её видимый текст, и никогда не копирует внутреннюю форму маршрутизации, которую MailCopilot использует для отображения ссылки. Для веб-адреса (`http:`/`https:`) с интернационализированным доменным именем адрес копируется в форме punycode (ASCII) -- именно в той форме, которую реально использует ваш браузер, -- а не в юникодной, чтобы скопированный адрес не мог скрыть похожий домен за читаемыми символами. Для адреса `mailto:` интернационализированный домен вместо этого кодируется через процентную запись, так как почтовые клиенты не разрешают его как punycode-хост. Учётные данные, встроенные в ссылку (`https://user:pass@host/…`), копируются как есть, без удаления -- если вы вставите такую ссылку в другое место, учётные данные попадут туда вместе с ней.

Ни один из пунктов не появляется для ссылок, которые не начинаются с `http:`, `https:` или `mailto:` (например, для встроенной в письмо ссылки `javascript:` или `data:`), а также для адреса ссылки длиннее 8192 символов.

## Действия с письмами

При чтении письма вы можете:

- **Ответить** -- написать ответ отправителю (клавиша **r**).
- **Ответить всем** -- ответить всем получателям (клавиша **a**).
- **Переслать** -- переслать письмо (клавиша **f**).
- **Пометить / Снять звёздочку** -- пометить как важное (клавиша **s**).
- **Удалить** -- переместить в Корзину (клавиша **#** или **Delete**).
- **Архивировать** -- переместить в Архив (клавиша **e**).
- **Спам** -- переместить в папку Спам (клавиша **!**).
- **Прочитано / Непрочитано** -- переключить статус (клавиши **Shift+I** / **Shift+U**).
- **Переместить в папку** -- переместить в конкретную папку (клавиша **v**). Перетаскивание письма на папку в боковой панели работает так же: каждое письмо перемещается из своей собственной исходной папки, поэтому перетаскивание из результата поиска **Все папки** или из переписки, письма которой лежат в разных папках, перемещает каждое письмо из той папки, где оно реально находится, а не из открытой в данный момент.
- **Отложить** -- временно скрыть письмо, чтобы оно появилось позже. Подробности ниже.
- **Закрепить / Открепить** -- закрепление письма в верхней части списка. Закреплённые письма всегда отображаются первыми, независимо от сортировки (горячая клавиша: **p**).
- **Открыть в окне** -- открыть письмо в отдельном самостоятельном окне, чтобы читать его одновременно с другим контентом.
- **Печать** -- печать текущего письма (горячая клавиша: **Ctrl+P**).

## Открыть в окне

Действие **Открыть в окне** открывает текущее письмо в отдельном самостоятельном окне. Это удобно, когда вы хотите читать письмо или работать с ним, не покидая основного окна с другими папками.

Отдельное окно — это полноценное рабочее место. В верхней части окна находится полная панель действий со всеми необходимыми кнопками:

- **Ответить** -- написать ответ отправителю.
- **Ответить всем** -- ответить всем получателям.
- **Переслать** -- переслать письмо другому адресату.
- **Архивировать** -- переместить письмо в папку «Архив». Кнопка неактивна, если для аккаунта не настроена папка «Архив».
- **Удалить** -- переместить письмо в «Корзину», если у аккаунта есть папка «Корзина». Если папки «Корзина» нет или письмо уже находится в «Корзине», MailCopilot запрашивает подтверждение перед безвозвратным удалением.
- **Пометить / Снять звёздочку** -- переключить статус «Отмечено» у письма.
- **Прочитано / Непрочитано** -- переключить статус прочтения.
- **Печать** -- распечатать тело письма.

При нажатии **Архивировать**, а также **Удалить** для письма, которое можно переместить в «Корзину», внизу окна на 3 секунды появляется встроенный баннер отмены, после чего MailCopilot выполняет перемещение и закрывает окно. Нажмите **Отменить**, чтобы отказаться от операции — письмо останется на месте, окно останется открытым. Пока баннер отмены виден, кнопки **Архивировать** и **Удалить** недоступны; **Ответить**, **Ответить всем**, **Переслать**, **Пометить / Снять звёздочку**, **Прочитано / Непрочитано** и **Печать** остаются доступными.

Если у аккаунта нет папки «Корзина», или письмо уже находится в «Корзине», **Удалить** запрашивает подтверждение перед безвозвратным удалением — баннер отмены при этом не появляется, действие необратимо.

Отдельное окно использует те же базовые средства защиты, что и основная панель чтения: очищенный HTML в изолированном iframe без скриптов, блокировку внешних изображений и предупреждения о фишинге для ссылок.

## Откладывание писем

Откладывание позволяет временно скрыть письмо и вернуть его в указанное время, чтобы вы могли разобраться с ним, когда будете готовы.

### Как отложить

Нажмите правой кнопкой мыши на письмо в списке и выберите **Отложить** в контекстном меню.

### Варианты откладывания

Выберите один из предустановленных вариантов или задайте произвольную дату и время:

- **Позже сегодня** -- ближайший получас.
- **Завтра утром (09:00)**.
- **На следующей неделе (понедельник 09:00)**.
- **Произвольное время** -- выберите любую дату и время в будущем.

### Папка «Отложенные»

Отложенные письма отображаются в папке **Отложенные** в боковой панели. Когда наступит указанное время, письмо снова становится видимым в своей исходной папке и вы получите уведомление.

Нажмите на любое отложенное письмо, чтобы открыть и прочитать его — откладывание при этом не отменяется. Чтобы вернуть письмо досрочно, нажмите кнопку **Отменить** рядом с ним.

## Прочитать позже

Функция «Прочитать позже» позволяет сохранить письма для последующего чтения — идеально для длинных рассылок, справочных материалов и всего, к чему вы хотите вернуться позже.

### Как добавить в «Прочитать позже»

- Нажмите правую кнопку мыши на письме и выберите **Прочитать позже** в контекстном меню.
- Или попросите AI-ассистента отметить письмо для чтения позже.

### Папка «Прочитать позже»

Отмеченные письма отображаются в папке **Прочитать позже** в боковой панели (иконка книги). В отличие от отложенных писем, письма из списка «Прочитать позже» остаются видимыми в своей исходной папке — это дополнительное представление, а не фильтр.

Нажмите на любое письмо в папке «Прочитать позже», чтобы открыть и прочитать его. Чтобы убрать письмо из списка, нажмите кнопку **Убрать из списка** рядом с ним.

Папку «Прочитать позже» можно открыть из боковой панели.

## Очень большие письма

MailCopilot защищается от патологически больших писем, но конкретная защита зависит от того, как письмо открывается.

**Жёсткий предел в 100 МБ защищает любое полное чтение письма.** Всякий раз, когда MailCopilot должен прочитать исходное содержимое письма целиком — открываете ли вы копию, уже сохранённую на устройстве, или MailCopilot полностью скачивает письмо, чтобы сделать его доступным офлайн, — письмо крупнее 100 МБ (в исходном виде, как оно хранится на сервере) вообще не разбирается. Это касается тела письма, вложений и любого встроенного приглашения на встречу. При открытии такого письма показывается карточка-заглушка, собранная из доступных сведений заголовков — отправитель, тема и дата, если они известны, — и пометка о том, что письмо крупнее предела в 100 МБ, без указания точного размера; если сама загрузка была прервана на середине, эти сведения берутся из уже синхронизированного списка писем, а не из самого письма, и могут быть неполными. Кнопки «всё равно открыть» здесь намеренно нет: это защита от нехватки памяти и от патологической или вредоносной почты, а не размер, с которым вы столкнётесь в обычной работе. Большинство обычных почтовых провайдеров отклоняют письма размером примерно 20–50 МБ ещё до того, как они попадут к вам во входящие, поэтому достичь этого предела должно быть крайне редким случаем — хотя и не невозможным: некоторые корпоративные почтовые системы (например, Microsoft 365 с повышенным организационным пределом) пропускают и более крупные письма. Само письмо на сервере остаётся нетронутым — его можно открыть в другой почтовой программе.

**Предел «показано только начало» в 1 МБ действует всякий раз, когда MailCopilot читает письмо через путь полного разбора, используемый для офлайн-доступа.** Сюда входят письма, открываемые из копии, уже сохранённой на устройстве, а также самое первое открытие письма в папке с включённым офлайн-доступом, когда MailCopilot скачивает письмо целиком, чтобы его показать, — даже если ограничения кэша не позволяют затем сохранить эту копию на диске. Это обычный случай для ваших Входящих, которые по умолчанию хранят недавние письма доступными офлайн, а также для любой другой папки, для которой вы включили офлайн-доступ (**Настройки > Папки**, см. [Офлайн-режим](../settings/folders-settings#offline-mode)). Для таких писем, если раскодированное тело превышает 1 МБ, показывается только начало: под текстом появляется плашка «Показано только начало письма.» Рядом с ней появляется кнопка **Показать письмо целиком**. Вложения на усечённом виде по-прежнему перечислены полностью. Нажмите кнопку, чтобы перечитать письмо с более высоким, но всё ещё конечным пределом (8 МБ) — MailCopilot делает это только тогда, когда вы явно об этом попросили. Если даже поднятого предела не хватает, чтобы показать письмо целиком, плашка остаётся, но вместо кнопки появляется пометка о том, что это всё, что MailCopilot может показать.

**На письма, открываемые напрямую с сервера, предел в 1 МБ / 8 МБ выше не распространяется.** Папки, для которых офлайн-доступ выключен — а это по умолчанию все папки, кроме Входящих, — при каждом открытии письма забирают его текст прямо с сервера, не скачивая и не сохраняя письмо целиком заранее. У такой загрузки есть собственные, отдельные пределы размера на каждый забираемый фрагмент, значительно меньше жёсткого предела в 100 МБ. При открытии очень большого письма таким способом ни заглушка, ни плашка «показано только начало» не появляются — MailCopilot просто может показать меньше содержимого очень большого письма, никак об этом не сообщая.

## Если письмо не удаётся загрузить

Если MailCopilot не может получить тело письма, вместо пустого экрана отображается заглушка. У этого есть три разные причины, и MailCopilot их различает, а не показывает одинаковое сообщение во всех случаях. Правило простое: заглушка говорит только то, что MailCopilot действительно знает, и не называет причину, о которой лишь догадывается:

**Вы попросили работать офлайн.** Включён режим «Работать офлайн», поэтому к серверу вообще не обращались, а тело письма никогда не загружалось — в локальном кэше есть только его заголовки:

> «Тело письма недоступно офлайн. Сохранены только заголовки.»

**Запрос не уложился в отведённое время.** На загрузку тела письма у MailCopilot есть 10 секунд, после чего попытка прекращается. Это секундомер, а не диагноз: он срабатывает, так и не выяснив, почему загрузка шла медленно. Чаще всего причина в том, что в момент открытия письма соединение с почтовым сервером занято фоновой работой — синхронизацией других папок, индексированием тел писем для поиска, — но ровно тот же результат дают медленный сервер, плохая связь или очень большое письмо. Письмо почти наверняка есть на сервере — MailCopilot просто не успел до него добраться:

> «Письмо не успело загрузиться за отведённое время. Так бывает, когда соединение занято фоновой работой, когда сервер отвечает медленно или когда письмо очень большое. Можно повторить.»

**Загрузка не удалась.** MailCopilot попытался загрузить тело письма и в итоге его не получил. Сюда попадает всё: и оборвавшаяся сеть, и пароль, который сервер больше не принимает, и неожиданный сертификат, и исчезнувшая папка, — а также то, что происходит *после* того, как письмо пришло, например нехватка места на диске при сохранении его в локальный кэш. MailCopilot сознательно не гадает, что именно из этого произошло, потому что заглушка ошибалась бы чаще, чем угадывала; по той же причине она не винит почтовый сервер, который в случае с местом на диске ни при чём. Там, где причина *известна*, её называет тот элемент интерфейса, который в ней уверен: полоса **Войти снова** над списком писем, когда перестали работать учётные данные, или диалог безопасности соединения, когда сертификату сервера не удалось доверять.

> «MailCopilot не смог загрузить тело этого письма — показаны только его заголовки. Можно повторить.»

Кнопка **Повторить** появляется под заглушкой во всех трёх случаях — и в главном окне, и в отдельном окне письма. Нажмите её, чтобы попытаться загрузить тело письма снова: при тайм-ауте обычно достаточно повторной попытки, когда фоновая работа завершится. Если включён режим «Работать офлайн» или устарел вход, повторные попытки будут давать ту же заглушку, пока вы не выключите режим офлайн или не войдёте заново.

## Приглашения на встречу

Если в письме содержится приглашение в календарь (вложение `.ics` в формате протокола iTIP), MailCopilot отображает встроенную карточку **Приглашение на встречу** над телом письма. Внешние приложения-календари или облачные сервисы не требуются.

В карточке отображается:

- **Название события** — заголовок встречи.
- **Когда** — дата и время начала. В большинстве случаев время пересчитывается и показывается в часовом поясе вашего устройства, независимо от того, в каком часовом поясе отправлял приглашение организатор; если часовой пояс приглашения отличается от вашего, под временем появляется подпись с исходным часовым поясом организатора, чтобы было сразу видно, что время было пересчитано. Пересчёт невозможен в двух случаях, и в обоих показывается исходное время организатора как есть: когда приглашение указывает часовой пояс, который MailCopilot не может распознать (некоторые приглашения Outlook/Exchange используют не стандартное, а Windows-имя часового пояса) — здесь подпись всё равно появляется и называет этот часовой пояс; и когда в приглашении вообще нет сведений о часовом поясе и нет явного смещения UTC — здесь подписи взяться неоткуда, поэтому она не показывается, а отображаемое время — это просто цифры организатора без указания, к какому часовому поясу они относятся.
- **Организатор** — организатор, указанный в календарном приглашении (может отличаться от отправителя письма, если приглашение отправлено от чьего-то имени).
- **Место** — переговорная комната или ссылка на конференцию, если указана.

Ниже данных события доступны три кнопки ответа: **Принять**, **Возможно** и **Отклонить**. При нажатии любой из них MailCopilot отправляет стандартный iTIP-ответ на email организатора через SMTP с использованием учётных данных вашего аккаунта. Карточка обновляется и подтверждает выбор (например, «Вы приняли приглашение»). Если ответ отправить не удалось, вместо подтверждения отображается сообщение об ошибке.

Кнопки Принять / Возможно / Отклонить отображаются только для актуальных приглашений на встречу (`METHOD:REQUEST`), где организатор — не вы. Отмены, публикации календарных лент, ответы и встречи, которые вы организуете сами, не показывают RSVP-кнопки — вместо них появится метка «Отменено» или «Не требует ответа».

### Ограничения в текущей версии

- **Интеграция с системным календарём отсутствует.** MailCopilot не добавляет событие в ваш календарь операционной системы (macOS Calendar, GNOME Calendar и т. д.). Это запланировано в будущих версиях.
- **Повторяющиеся события.** Регулярные встречи отображаются как единичное событие; шаблон повторения не показывается.
- **Встречные предложения.** Предложить другое время нельзя — доступны только «Принять», «Возможно» и «Отклонить».
- **Отменённые события.** Если организатор отменил встречу, в карточке отображается «Мероприятие отменено», а кнопки ответа скрыты.

## Отмена действий

В режимах просмотра отдельных папок архивирование, пометка как спам или перемещение в корзину показывают панель отмены с обратным отсчётом. Нажмите **Отменить** до истечения таймера. Возможность отмены решает то, какие письма действие реально перемещает, а не то, из каких папок была составлена ваша исходная выборка: письма, уже лежащие в целевой папке, или письма аккаунта без папки для этой роли, откладываются в сторону и не перемещаются. Панель отмены всегда покрывает только одну исходную папку, поэтому она появляется лишь тогда, когда все реально перемещаемые письма пришли из папки, которая сейчас открыта. Удаление может быть смешанным: письма, уходящие в «Корзину», получают панель отмены, если удовлетворяют этому условию, а письма, уже лежащие в «Корзине», или письма аккаунта без папки «Корзина», удаляются безвозвратно — MailCopilot просит подтверждения и ждёт вашего ответа, а не действует немедленно. Действия между аккаунтами, а также любое действие, перемещаемые письма которого по-прежнему разбросаны по нескольким исходным папкам — например, массовое действие над выборкой из поиска **Все папки**, — панель отмены не показывают: эта часть действия всё равно выполняется сразу, папка за папкой, просто отменить её одним шагом уже нельзя.
