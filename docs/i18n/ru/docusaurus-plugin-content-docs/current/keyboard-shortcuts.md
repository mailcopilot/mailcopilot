# Горячие клавиши

MailCopilot поддерживает горячие клавиши для быстрой навигации. Нажмите **?** в приложении, чтобы открыть справочник.

Ниже приведены горячие клавиши пресета **Gmail** (по умолчанию). Переключить на **Outlook** можно в **Настройки > Продуктивность > Пресет горячих клавиш**.

## Навигация

| Клавиша | Действие |
|---------|----------|
| **j** / **k** | Следующее / предыдущее письмо |
| **o** или **Enter** | Открыть письмо |
| **u** | Вернуться к списку |
| **/** | Фокус на поиске |
| **g** затем **i** | Входящие |
| **g** затем **s** | Отправленные |
| **g** затем **d** | Черновики |
| **g** затем __*__ | Помеченные |
| **g**, затем **r** | Перейти к «Прочитать позже» |

## Действия

| Клавиша | Действие |
|---------|----------|
| **c** | Написать письмо |
| **r** | Ответить |
| **a** | Ответить всем |
| **f** | Переслать |
| **s** | Пометить / снять звёздочку |
| **e** | Архивировать |
| **Shift+I** | Отметить прочитанным |
| **Shift+U** | Отметить непрочитанным |
| **!** | Пометить как спам |
| **x** | Выделить / снять выделение |
| **v** | Переместить в папку |
| **z** | Отменить действие |
| **#** или **Delete** | Удалить |
| **Escape** | Сбросить выделение |
| **p** | Закрепить / открепить письмо |
| **Ctrl+P** | Печать письма |

## AI

| Клавиша | Действие |
|---------|----------|
| **Ctrl+Shift+S** | Быстрое AI-резюмирование |

## Контекстное меню

Нажмите правой кнопкой мыши на любое письмо в списке, чтобы открыть контекстное меню. Оно предоставляет быстрый доступ к действиям (ответить, архивировать, переместить и другие) без открытия письма.

## Общие

| Клавиша | Действие |
|---------|----------|
| **Ctrl+K** | Палитра команд |
| **?** | Показать горячие клавиши |

## Палитра команд

Нажмите **Ctrl+K**, чтобы открыть палитру команд. Начните вводить для поиска:

- Написать письмо
- Синхронизировать
- Фокус на поиске
- Открыть настройки
- Перейти в папки (Входящие, Отложенные, Напоминания, Прочитать позже)
- Показать помеченные
- Единый ящик
- Включить/отключить группировку
- Переключить аккаунт
- AI-действия
