# Установка

## Скачивание MailCopilot

Перейдите на [mailcopilot.io](https://mailcopilot.io), чтобы скачать последнюю версию MailCopilot для вашей платформы.

## Установка на Linux

:::warning Ubuntu 23.10+ / 24.04 и другие современные дистрибутивы
На Ubuntu 23.10 и более поздних версиях (включая 24.04 LTS), а также на других дистрибутивах с аналогичным ужесточением ядра **устанавливайте пакет `.deb`** (или `.rpm` на Fedora/openSUSE) вместо AppImage.

В этих ядрах по умолчанию ограничены непривилегированные пространства имён пользователей (`kernel.apparmor_restrict_unprivileged_userns=1`). MailCopilot основан на Electron, чей вспомогательный компонент `chrome-sandbox` требует этой возможности при запуске из AppImage — поэтому AppImage аварийно завершается при старте с сигналом `SIGTRAP`. Пакеты `.deb` и `.rpm` лишены этой проблемы: их установочные скрипты настраивают вспомогательный компонент `chrome-sandbox` надлежащим образом — устанавливая SUID-root (`chmod 4755`) там, где непривилегированные пространства имён пользователей ограничены, либо устанавливая профиль AppArmor на более новых системах Ubuntu (24.04+).

**Не** обходите это ограничение запуском с `--no-sandbox` или глобальным отключением `apparmor_restrict_unprivileged_userns` — оба варианта ослабляют границу безопасности, защищающую вас от ненадёжного содержимого писем. Используйте вместо этого `.deb` или `.rpm`.
:::

### Deb (Debian, Ubuntu, Mint) — рекомендуется

1. Скачайте файл `.deb` с сайта.
2. Установите, дважды щёлкнув по файлу, или выполните в терминале:
   ```bash
   sudo dpkg -i mailcopilot-*.deb
   ```
3. Запустите MailCopilot из меню приложений.

### RPM (Fedora, openSUSE)

1. Скачайте файл `.rpm` с сайта.
2. Установите, дважды щёлкнув по файлу, или выполните в терминале:
   ```bash
   sudo rpm -i mailcopilot-*.rpm
   ```
3. Запустите MailCopilot из меню приложений.

### AppImage

AppImage — это единый самодостаточный файл, не требующий установки. Он хорошо работает на более старых дистрибутивах, однако перед использованием на Ubuntu 23.10+ / 24.04 ознакомьтесь с предупреждением выше.

1. Скачайте файл `.AppImage` с сайта.
2. Сделайте файл исполняемым:
   - Щёлкните правой кнопкой мыши по файлу, выберите **Свойства**, перейдите на вкладку **Права** и включите **Разрешить выполнение файла как программы**.
   - Или выполните в терминале: `chmod +x mailcopilot-*.AppImage`
3. Дважды щёлкните по AppImage, чтобы запустить MailCopilot.

Для работы AppImage требуется FUSE. На свежих выпусках Debian/Ubuntu установите пакет `libfuse2t64` (в старых выпусках он называется `libfuse2`):

```bash
sudo apt install libfuse2t64
```

:::tip
Вы можете переместить AppImage в любое удобное место, например `~/Applications/`. Приложение полностью автономно и не требует установки.
:::

## Установка на Windows

1. Скачайте установщик `.exe` с сайта.
2. Запустите установщик и следуйте инструкциям на экране. Вы можете выбрать папку установки.
3. Запустите MailCopilot из меню «Пуск» или ярлыка на рабочем столе.

## Первый запуск

При первом запуске MailCopilot сначала показывается экран согласия с заголовком **Отправлять диагностические данные?** — можно ли отправлять диагностические данные и сведения об использовании; о том, что именно это значит, см. [Телеметрия](../privacy/telemetry). Пока вы не ответите, ничего не отправляется, и ваш выбор не влияет ни на синхронизацию почты, ни на работу ИИ-ассистента. Он меняет одну вещь в Настройках → О программе: при выключенной диагностике встроенная форма обратной связи заменяется ссылкой на сайт MailCopilot. После ответа откроется мастер настройки аккаунта, который проведёт вас через подключение первого почтового аккаунта.

Ваши пароли надёжно хранятся в системной связке ключей (через keytar) и никогда не записываются в текстовые файлы конфигурации.

## Автоматические обновления

MailCopilot автоматически проверяет наличие обновлений. Когда доступна новая версия, в приложении появится уведомление. Вы можете скачать обновление и перезапустить приложение одним нажатием.

:::note
Встроенный механизм обновления MailCopilot может попытаться обновить себя на месте для установок AppImage, `.deb`/`.rpm`/pacman, а также на Windows и macOS. Для AppImage MailCopilot заменяет сам файл `.AppImage`, поэтому он должен храниться там, куда ваша учётная запись может писать — например, в домашнем каталоге. Для пакета `.deb`/`.rpm`/pacman механизм обновления запрашивает права администратора (`pkexec`/`sudo`) перед попыткой записать обновление — так же, как это делают `apt`/`dnf`/`pacman`, — поэтому принадлежность каталога установки пользователю root этому не мешает, хотя итоговый результат зависит от этого запроса на повышение прав и менеджера пакетов, а не от самого MailCopilot. Самообновление заранее недоступно только тогда, когда MailCopilot запущен не в одной из этих упакованных форм (например, это распакованный AppImage или необработанный каталог), либо когда каталог, в который MailCopilot нужно было бы записать обновление, недоступен для записи — каталог самого AppImage, либо на Windows и macOS каталог, в котором установлен исполняемый файл. В этих случаях обновляйтесь через менеджер пакетов, с правами администратора или скачав и переустановив последний пакет с сайта.
:::
