# Настройки продуктивности

Вкладка «Продуктивность» в настройках содержит параметры для эффективной работы с почтой.

## Уведомления на рабочем столе

Включите или отключите системные уведомления о новой входящей почте. Когда опция включена, MailCopilot уведомляет о новой почте, которая приходит в папку, учитываемую в [значке непрочитанных писем](general#значок-непрочитанных-писем) — по умолчанию это Входящие, а также любая папка, которую вы явно включили в подсчёт значка — и только если для этой папки настроена полная или периодическая синхронизация заголовков. Сверх этого MailCopilot по умолчанию пропускает фиксированный набор папок — Корзину, Спам, Архив и Черновики — даже если вы явно включили одну из них в значок; это дополнительно сужает круг уведомлений и никогда не расширяет его за пределы политики значка. Папки, исключённые из значка, или синхронизируемые только вручную, никогда не приводят к уведомлению, даже если в них приходит новая почта.

Пока окно MailCopilot находится в фокусе, уведомление о новой почте не показывается: значок и список писем обновляются как обычно, но появление письма не прерывает вас всплывающим уведомлением, ведь вы уже смотрите в приложение. Если несколько писем приходят за короткий промежуток времени, пока приложение работает в фоне, MailCopilot показывает одно уведомление на аккаунт (например, **«Новых писем: 5»**) вместо отдельного тоста на каждое письмо — если почта одновременно приходит на два аккаунта, вы всё равно получите два отдельных уведомления; нажатие на уведомление открывает это письмо. На неподписанных сборках для macOS операционная система может вообще не разрешать показ уведомлений.

## IMAP IDLE (мгновенные обновления)

Когда включено, MailCopilot поддерживает постоянное соединение с сервером и мгновенно получает уведомления о новых письмах. Отключите, если предпочитаете ручную синхронизацию.

## Интервал синхронизации

Выберите, как часто MailCopilot автоматически проверяет новые письма (1, 2, 5, 10, 15 или 30 минут). Если включён IMAP IDLE, интервал служит лишь подстраховкой — новые письма приходят мгновенно. Увеличьте интервал, чтобы снизить нагрузку на сервер.

## Синхронизация черновиков

Черновики автоматически сохраняются в папку «Черновики» на IMAP-сервере. Это позволяет получить доступ к черновикам из других почтовых клиентов.

## Всегда загружать внешние изображения

По умолчанию внешние изображения блокируются. Включите для загрузки без баннера конфиденциальности.

## Фото отправителей (Gravatar)

Когда включено (по умолчанию), MailCopilot показывает фотографии профилей рядом с именами отправителей в списке писем. Фото загружаются с [Gravatar](https://gravatar.com) — бесплатного сервиса, который связывает аватар с email-адресом. Если у отправителя нет профиля Gravatar, вместо фото отображается цветной кружок с инициалами.

Отключите эту опцию, если предпочитаете аватары только с инициалами или хотите избежать сетевых запросов при просмотре почты.

## Тёмная тема для содержимого писем

При использовании тёмной темы HTML-содержимое писем может быть трудно читать, так как многие письма рассчитаны на белый фон. Включите эту опцию (включена по умолчанию), чтобы автоматически инвертировать цвета содержимого писем в тёмном режиме для комфортного чтения.

Изображения, видео и другие медиа сохраняют оригинальные цвета — инвертируются только текст и фон.

## Порядок сортировки

Выберите порядок сортировки списка писем:

- **По дате** (по умолчанию) -- сначала новые письма.
- **По отправителю** -- по алфавиту имени отправителя.
- **По теме** -- по алфавиту темы письма.

## Автопереход

Выберите, что происходит после архивации, удаления или откладывания письма:

- **Открыть более старое письмо** (по умолчанию) -- автоматически открывает следующее по дате письмо, как в Gmail.
- **Открыть более новое письмо** -- открывает предыдущее более новое письмо.
- **Вернуться к списку** -- закрывает детали письма и возвращает к списку.
- **Остаться (ничего не делать)** -- оставляет текущий вид без активного письма.

Особенно удобно в сочетании с [Отправить и архивировать](../usage/composing-emails#send--archive) для методики inbox-zero.

## Группировка в цепочки

Связанные письма группируются в цепочки для удобного чтения. Отключите, если предпочитаете плоский список.

## Пресет горячих клавиш

Выберите между пресетами:

- **Gmail** -- горячие клавиши в стиле Gmail.
- **Outlook** -- горячие клавиши в стиле Outlook.

Полный список см. на странице [Горячие клавиши](../keyboard-shortcuts).

## Задержка отправки

Добавьте задержку перед фактической отправкой:

- **Выкл** -- письма отправляются сразу.
- **5 / 10 / 30 секунд** -- письмо удерживается в Исходящих. В это время можно отменить отправку.

## Офлайн-режим

Загружайте письма для чтения без подключения к интернету. Офлайн-режим настраивается **для каждой папки** на вкладке [Папки](folders-settings#offline-mode) — вы можете включить его для Входящих, Отправленных или любой другой папки по отдельности.

На вкладке «Продуктивность» находится только глобальное ограничение размера:

- **Макс. размер письма** — пропускать письма больше указанного размера (0 = без ограничений, в КБ).
- **Синхронизировать сейчас** — запустить офлайн-синхронизацию вручную для всех включённых папок.

Когда вы открываете письмо в офлайн-режиме, MailCopilot показывает кэшированные заголовки (тема, отправитель, дата) и индикатор, что тело письма недоступно. После восстановления соединения полное письмо загружается в обычном режиме.
