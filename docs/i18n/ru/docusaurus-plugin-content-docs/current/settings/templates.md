# Шаблоны

Вкладка «Шаблоны» в настройках позволяет создавать, редактировать и удалять шаблоны писем для повторного использования.

## Создание шаблона

1. Перейдите в **Настройки > Шаблоны**.
2. Нажмите кнопку **Добавить шаблон**.
3. Заполните поля:
   - **Название** -- короткое имя для идентификации шаблона (например, «Быстрый ответ»).
   - **Тема** -- тема письма, например `Re: {subject}` (необязательно).
   - **Текст** -- текст сообщения, например `Привет, {name}, спасибо, что написали…`
   - **Ярлык** -- необязательное короткое ключевое слово для быстрого поиска шаблона.
4. Нажмите **Сохранить**.

## Редактирование шаблона

Нажмите **значок карандаша** рядом с шаблоном, чтобы отредактировать его. После внесения изменений нажмите **Сохранить**.

## Удаление шаблона

Нажмите **значок корзины** рядом с шаблоном, чтобы удалить его. Удалённые шаблоны восстановить нельзя.

## Переменные шаблонов

В теме и тексте шаблона можно использовать переменные. Они автоматически подставляются при применении шаблона в окне написания:

| Переменная | Подставляется |
|------------|---------------|
| `{name}` | Имя получателя |
| `{email}` | Адрес электронной почты получателя |
| `{date}` | Сегодняшняя дата |

### Пример

**Текст шаблона:**
```
Уважаемый {name},

Спасибо за ваше письмо. Я рассмотрю его и свяжусь с вами в ближайшее время.

С уважением
```

При применении к письму, адресованному «Алексей Иванов», переменная `{name}` будет заменена на «Алексей Иванов».

## Использование шаблонов

Чтобы использовать шаблон при написании письма, смотрите [Написание писем > Использование шаблонов](../usage/composing-emails#использование-шаблонов).
