# Подписи

## Настройка подписи

Откройте **Настройки > Подпись**, чтобы создать или изменить подпись. Вкладка «Подписи» редактирует подпись **личности по умолчанию** выбранного аккаунта. Если аккаунтов несколько, выберите нужный из выпадающего списка вверху; если у аккаунта есть дополнительные личности (альтернативные From-адреса), у каждой своя подпись — редактируются они в **Настройки > Identities**.

## Составление подписи

Введите текст подписи. Типичный формат:

```
--
Иван Иванов
Программист
ООО «Компания»
ivan@example.com
```

Разделитель `--` -- стандартный разделитель подписи, распознаваемый большинством почтовых клиентов.

## Как работают подписи

- Подпись **автоматически добавляется** к новым письмам.
- Подпись **не добавляется** к ответам и пересылкам.
- При редактировании черновика существующая подпись сохраняется.
- У каждой личности по умолчанию своя подпись; у дополнительных личностей подписи свои и редактируются в **Настройки > Identities**.

## Удаление подписи

Чтобы удалить подпись, очистите текстовое поле в **Настройки > Подпись** и сохраните.

## Подписи и личности

Подписи теперь живут per-identity (на уровне личности), а не на уровне аккаунта. Вкладка **Подписи** на этой странице редактирует подпись личности по умолчанию у выбранного аккаунта. Если у аккаунта есть дополнительные личности (другие From-адреса в одном и том же аккаунте — например, личный алиас или командный алиас), у каждой личности своя подпись — редактируйте их в **Настройки > Identities**. См. [Личности](./identities) о том, как устроены личности и как окно написания письма выбирает одну из них при ответе или новом сообщении.
