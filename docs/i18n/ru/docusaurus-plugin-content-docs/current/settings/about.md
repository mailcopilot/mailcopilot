# О программе

Вкладка **О программе** в Настройках отображает информацию о вашей установке MailCopilot и предоставляет элементы управления диагностикой и обновлениями.

## Версия

Показывает текущую версию MailCopilot, установленную на вашем компьютере.

## Ссылки

- **Сайт** — открывает сайт MailCopilot в вашем браузере.
- **Документация** — открывает этот сайт документации.

## Системная информация

Панель **Системная информация** отображает технические сведения об установке:

- **Версия приложения** — текущая версия MailCopilot и канал выпуска (stable, nightly или dev).
- **Electron** — версия среды выполнения Electron.
- **Chromium** — версия движка Chromium, включённого в Electron.
- **Node.js** — версия Node.js, используемая внутри приложения.
- **Платформа** — операционная система и архитектура.
- **Путь установки** — директория, в которую установлен MailCopilot. Если путь помечен как **только для чтения**, установка выполнена для всей системы и автоматические обновления требуют прав администратора.

Эта информация полезна при сообщении об ошибках и проверке совместимости.

## Обновления

Раздел **Обновления** позволяет управлять тем, как MailCopilot обновляет себя.

### Автоматически скачивать обновления в фоне

Когда эта опция включена, MailCopilot незаметно загружает новые версии по мере их появления. После завершения загрузки вам предлагается перезапустить приложение для применения обновления. Никаких действий не требуется до тех пор, пока вы не будете готовы к перезапуску.

Когда эта опция отключена, MailCopilot уведомляет о наличии обновления и показывает кнопку **Скачать**. Вы сами выбираете, когда начать загрузку.

Эта настройка **отключена по умолчанию** (требует явного включения). Включите её, чтобы MailCopilot загружал обновления без вашего участия.

### Проверить обновления

Нажмите кнопку **Проверить обновления**, чтобы вручную запустить проверку в любой момент. Кнопка и область статуса отражают текущее состояние процесса обновления:

- **ожидание** — кнопка **Проверить обновления** видна и готова к использованию.
- **Проверка…** — выполняется проверка наличия обновлений; кнопка недоступна до завершения.
- **У вас самая свежая версия** — обновлений нет.
- **Доступно обновление: vX.Y.Z** — обнаружена новая версия; появляется кнопка **Скачать X.Y.Z**, если установка поддерживает самообновление.
- **Загрузка… N%** — файл обновления загружается; отображается индикатор прогресса.
- **Перезапустить и установить** — загрузка завершена; нажмите, чтобы немедленно перезапустить MailCopilot и применить обновление.
- **Сетевая ошибка — повторите, когда будете онлайн** — проверка или загрузка не удались из-за проблем с сетью.
- **Доступ запрещён — нужен администратор** — директория установки недоступна для записи текущим пользователем.
- **Не удалось обновить — подробности в логах** — произошла непредвиденная ошибка; обратитесь к разделу расширенного логирования.
- **Обновления отключены в этой сборке** — MailCopilot запущен в режиме разработки или не упакован; автоматические обновления недоступны.

### Системные установки (только для чтения)

Если MailCopilot был установлен для всей системы (например, через менеджер пакетов, размещающий приложение в защищённой директории), путь установки в разделе «Системная информация» помечается как **только для чтения**. В этом случае:

- Флажок **Автоматически скачивать обновления в фоне** отображается, но **заблокирован** (затемнён) с всплывающей подсказкой о том, что установка доступна только для чтения.
- Кнопка **Проверить обновления** **по-прежнему работает** — вы можете проверить наличие новой версии.
- Кнопки **Скачать** и **Перезапустить и установить** недоступны: они не отображаются или не функционируют для системных установок, так как MailCopilot не может записать обновление в защищённую директорию.

Обновляйте приложение через менеджер пакетов или с правами администратора.

## Анонимные отчёты об ошибках

Когда включено, MailCopilot отправляет анонимные отчёты о сбоях, чтобы помочь разработчикам находить и исправлять ошибки. Личные данные, содержимое писем или информация об аккаунтах никогда не собираются — передаются только технические детали ошибок.

Эта настройка включена по умолчанию. Вы можете отключить её в любое время, сняв флажок.

## Расширенное логирование

Когда включено, MailCopilot записывает подробные логи в файл для диагностики проблем. Логи хранятся локально на вашем компьютере и никогда не отправляются автоматически.

Расширенное логирование отключено по умолчанию. Включайте его только при расследовании проблемы — это может незначительно влиять на производительность.

## Сообщить об ошибке

Нажмите кнопку **Сообщить об ошибке**, чтобы отправить обратную связь напрямую разработчикам MailCopilot. Опишите возникшую проблему — это поможет нам быстрее находить и исправлять ошибки.

Обратная связь отправляется безопасно через ту же систему анонимных отчётов. Если отправка отчётов отключена, вы увидите ссылку на сайт MailCopilot, где можно обратиться в поддержку.

Если приложение сталкивается с непредвиденной ошибкой, форма обратной связи также появится на экране ошибки, позволяя описать, что вы делали перед возникновением ошибки.
