# Настройки папок

Откройте **Настройки > Папки**, чтобы настроить работу MailCopilot с вашими почтовыми папками.

## Маппинг ролей папок

MailCopilot нужно знать, какая серверная папка соответствует каждой роли (Архив, Корзина, Отправленные, Черновики, Спам). Это определяется автоматически, но вы можете переопределить маппинг вручную.

Для каждой роли можно:
- Оставить **Авто** для автоматически определённой папки.
- Выбрать конкретную папку из списка.
- Нажать **Создать**, чтобы создать стандартную папку на сервере.

## Политика синхронизации папок

Ниже маппинга ролей -- детальная настройка для каждой папки:

### Видимость

- **Показывать в боковой панели** -- отображается ли папка в боковой панели.

### Бейджи непрочитанных

- **Включить в бейджи непрочитанных** -- учитывать ли непрочитанные этой папки в общем бейдже.

### Индексация для поиска

- **Включить в поиск** -- индексировать ли тела писем этой папки для полнотекстового поиска. Если отключено, папка по-прежнему видна в списке писем, а заголовки доступны для поиска, однако запросы `body:` не возвращают результаты из неё.

Папки «Нежелательная почта», «Спам» и «Корзина» по умолчанию исключены из индексации, чтобы не засорять результаты поиска и снизить использование диска. При необходимости вы можете включить индексацию для любой папки.

### Режим синхронизации заголовков

- **Все сообщения** -- синхронизировать все заголовки (рекомендуется для Входящих).
- **При открытии** -- синхронизировать при переходе в папку.
- **За период** -- синхронизировать заголовки за последние N дней.

Чтобы полностью отключить синхронизацию папки, скройте её через **Скрыть из боковой панели** в контекстном меню. Скрытые папки полностью исключаются из синхронизации заголовков, офлайн-хранилища и бейджей.

### Офлайн-режим {#offline-mode}

- **Отключено** -- не загружать тела писем.
- **За период** -- загружать тела за последние N дней.
- **Все сообщения** -- загружать все тела писем.

## Выбор аккаунта

При наличии нескольких аккаунтов используйте переключатель вверху для настройки папок каждого аккаунта.
