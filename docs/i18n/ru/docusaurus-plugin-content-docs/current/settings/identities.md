# Личности (Identities)

У одного почтового аккаунта может быть несколько **личностей** — альтернативных адресов, от которых вы отправляете письма. Это удобно для аккаунтов Gmail или Microsoft 365, где помимо основного адреса есть алиасы (личный алиас, командный алиас, старый адрес «для красоты»), и вы хотите, чтобы у каждого было собственное отображаемое имя, подпись и правила Bcc — без необходимости заводить каждый алиас отдельным IMAP-аккаунтом.

## Что входит в личность

Каждая личность содержит:

- **Отображаемое имя** — то, как получатель видит вас в поле «From».
- **Адрес электронной почты** — фактический адрес, используемый в поле «From». Это должен быть адрес, от имени которого аккаунт уполномочен отправлять.
- Необязательную **подпись** — заменяет общую подпись аккаунта, когда выбрана данная личность. См. [Подписи](./signatures) о том, как подписи ведут себя при ответах и пересылках.
- Необязательный **Bcc по умолчанию** — автоматически добавляется в поле Bcc каждый раз, когда эта личность выбрана в окне «Написать».
- **Признак «по умолчанию»** — ровно одна личность на аккаунт является основной. Личность по умолчанию используется, когда никакое более специфичное правило не сработало.

У каждого аккаунта всегда есть как минимум одна личность. При первом входе MailCopilot создаёт единственную личность по умолчанию из имени аккаунта, его email и существующей подписи.

## Управление личностями

Откройте **Настройки > Identities** и выберите нужный аккаунт из выпадающего списка вверху. На вкладке отображается список личностей этого аккаунта с кнопками:

- **Добавить** новую личность. Заполните отображаемое имя, email, подпись и Bcc по умолчанию; при необходимости отметьте её как личность по умолчанию.
- **Редактировать** существующую личность, чтобы изменить любое поле.
- **Сделать по умолчанию** — повысить любую личность до основной. Только одна личность одновременно может быть личностью по умолчанию.
- **Удалить** личность. Личность по умолчанию удалить нельзя — сначала назначьте основной другую личность.

## Выбор личности при написании письма

В окне написания письма выпадающий селектор личности располагается сразу под аккаунт-выпадающим списком «From». По умолчанию MailCopilot выбирает личность за вас в следующем порядке:

1. **Ответы и пересылки** — сопоставление с полями From, To и Cc исходного письма. Побеждает первая личность, чей email встречается в этом списке, чтобы ответ ушёл с того же адреса, на который вы изначально получили сообщение. Сравнение нечувствительно к регистру по полному email; цепочки алиасов и варианты с плюс-адресами не сопоставляются и откатываются на личность по умолчанию.
2. **Новые письма** — выбирается личность аккаунта по умолчанию.

Вы можете в любой момент переопределить выбор, открыв выпадающий список и указав другую личность. Смена личности обновляет заголовок «From». Подпись заменяется только когда тело письма пусто или содержит только подпись-блок после стандартного разделителя `\n\n--\n` — введённый вами текст над разделителем не затирается. Поле Bcc заменяется только когда оно пусто или совпадает с Bcc-по-умолчанию ранее выбранной личности, поэтому Bcc, который вы вписали вручную, переживёт смену личности.

## Связь с подписями

Подписи теперь живут **per-identity**, не per-account. Вкладка **Настройки > Подписи** редактирует подпись личности по умолчанию у выбранного аккаунта; остальные личности редактируются в **Настройки > Identities**. Аккаунты, созданные до выкатки multi-identity, сохраняют свою старую per-account подпись: MailCopilot читает её через синтезированную личность по умолчанию, поэтому ничего не ломается. Полноценный список личностей записывается на диск при следующем сохранении аккаунта (например, когда вы редактируете любое поле аккаунта).

## Отправка и аудит

Та личность, которая активна в окне написания на момент отправки, попадает в фактическое исходящее сообщение:

- Заголовок «From» в SMTP / Microsoft Graph несёт email и отображаемое имя личности.
- Запланированные отправки запоминают личность, выбранную на момент планирования: письмо, запланированное от вашего алиаса, уйдёт от этого алиаса и при срабатывании таймера.
