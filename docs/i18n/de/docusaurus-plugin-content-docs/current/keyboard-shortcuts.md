# Tastaturkuerzel

Druecken Sie **?** fuer die Uebersicht. Standard-Preset: **Gmail**.

## Navigation

| Kuerzel | Aktion |
|---------|--------|
| **j** / **k** | Naechste / vorherige Nachricht |
| **o** oder **Enter** | Nachricht oeffnen |
| **u** | Zurueck zur Liste |
| **/** | Suche fokussieren |
| **g** dann **i** | Posteingang |
| **g** dann **s** | Gesendet |
| **g** dann **d** | Entwuerfe |
| **g** dann __*__ | Markiert |
| **g** dann **r** | Zu „Später lesen" |

## Aktionen

| Kuerzel | Aktion |
|---------|--------|
| **c** | Verfassen |
| **r** | Antworten |
| **a** | Allen antworten |
| **f** | Weiterleiten |
| **s** | Markieren |
| **e** | Archivieren |
| **Shift+I** | Als gelesen markieren |
| **Shift+U** | Als ungelesen markieren |
| **!** | Spam |
| **x** | Auswaehlen |
| **v** | Verschieben |
| **z** | Rueckgaengig |
| **#** oder **Delete** | Loeschen |
| **Escape** | Auswahl aufheben |
| **p** | Nachricht anheften / lösen |
| **Ctrl+P** | Nachricht drucken |

## KI

| Kuerzel | Aktion |
|---------|--------|
| **Ctrl+Shift+S** | KI-Schnellzusammenfassung |

## Kontextmenue

Klicken Sie mit der rechten Maustaste auf eine beliebige Nachricht in der Liste, um das Kontextmenue zu oeffnen. Es bietet schnellen Zugriff auf Aktionen (Antworten, Archivieren, Verschieben u. a.), ohne die Nachricht zu oeffnen.

## Allgemein

| Kuerzel | Aktion |
|---------|--------|
| **Ctrl+K** | Befehlspalette (schneller Zugriff auf Ordner, einschliesslich Schlummern, Nachverfolgung und Spaeter lesen) |
| **?** | Tastaturkuerzel anzeigen |
