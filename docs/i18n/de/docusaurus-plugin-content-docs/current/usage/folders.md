# Ordner

## Navigation

Klicken Sie auf einen Ordner in der Seitenleiste. Kuerzel: **g** dann **i** (Posteingang), **g** dann **s** (Gesendet), **g** dann **d** (Entwuerfe), **g** dann __*__ (Markiert).
- **g**, dann **r** — zum Ordner „Später lesen"

## Spezialordner

MailCopilot erkennt die folgenden Spezialordner:

| Ordner | Beschreibung |
|--------|--------------|
| **Posteingang** | Ihre eingehenden Nachrichten. |
| **Gesendet** | Nachrichten, die Sie versendet haben. |
| **Entwuerfe** | Nicht gesendete Nachrichtenentwuerfe. |
| **Papierkorb** | Geloeschte Nachrichten. Von hier koennen sie endgueltig geloescht werden. |
| **Spam** | Als Spam markierte Nachrichten. |
| **Archiv** | Archivierte Nachrichten, die Sie aufbewahren, aber aus dem Posteingang entfernen moechten. |
| **Postausgang** | Nachrichten, die fuer den verzoegerten oder zeitgesteuerten Versand vorgemerkt sind. |
| **Schlummern** | Nachrichten, die Sie schlummern lassen. Sie erscheinen wieder, wenn die Schlummerzeit abgelaufen ist. |
| **Nachverfolgung** | E-Mails mit eingestellten Erinnerungen für ausstehende Antworten. |
| **Später lesen** | E-Mails, die zum späteren Lesen markiert wurden. Im Gegensatz zu zurückgestellten bleiben sie im Originalordner. |

MailCopilot erkennt automatisch, welcher Serverordner welcher Spezialrolle entspricht. Sie koennen diese Zuordnung bei Bedarf unter **Einstellungen > Ordner** aendern.

## Nachrichten verschieben

Drag & Drop, Kontextmenue, Taste **v** oder Aktions-Buttons.

## Ordner-Kontextmenue

Rechtsklick auf einen Ordner in der Seitenleiste:

- **Alle Header synchronisieren** / **Beim Öffnen synchronisieren** -- steuert die Kopfzeilen-Synchronisierung.
- **In Suche einbeziehen** / **Aus Suche ausschließen** -- aktiviert oder deaktiviert die Indexierung des Nachrichtentexts für die Volltextsuche (`body:`). Für Junk-, Spam- und Papierkorb-Ordner standardmäßig deaktiviert.
- **In Ungelesen-Badges anzeigen** / **Aus Ungelesen-Badges ausblenden** -- Einbeziehung ins Gesamt-Badge.
- **In der Seitenleiste anzeigen** / **Aus der Seitenleiste ausblenden** -- Sichtbarkeit steuern.
- **Icon ändern** -- benutzerdefiniertes Emoji oder Icon festlegen.
- **Ordner umbenennen** -- auf dem Server umbenennen.
- **Ordner löschen** -- vom Server entfernen (Bestätigung erforderlich).

## Ungelesen-Badges

Jeder Ordner zeigt ein Badge mit der Anzahl ungelesener Nachrichten an. Schlummernde Nachrichten werden automatisch von diesen Zaehlerstaenden ausgeschlossen -- sie erhoehen Ihre Ungelesen-Badges nicht, solange sie zurueckgestellt sind.

Sie koennen anpassen, welche Ordner Ungelesen-Badges anzeigen:

- Rechtsklick auf einen Ordner und **In Ungelesen-Badges anzeigen** oder **Aus Ungelesen-Badges ausblenden** waehlen.
- Oder unter **Einstellungen > Ordner** in den Ordner-Synchronisierungsrichtlinien konfigurieren.

## Endgueltiges Loeschen

Das Loeschen aus dem Papierkorb ist endgueltig. Ein Bestaetigungsdialog erscheint.
