# Scorciatoie da tastiera

Premi **?** per visualizzare il riferimento. Preset predefinito: **Gmail**.

## Navigazione

| Scorciatoia | Azione |
|-------------|--------|
| **j** / **k** | Messaggio successivo / precedente |
| **o** o **Enter** | Aprire il messaggio |
| **u** | Tornare alla lista |
| **/** | Mettere a fuoco la ricerca |
| **g** poi **i** | Posta in arrivo |
| **g** poi **s** | Inviati |
| **g** poi **d** | Bozze |
| **g** poi __*__ | Con stella |
| **g** poi **r** | Vai a «Leggi più tardi» |

## Azioni

| Scorciatoia | Azione |
|-------------|--------|
| **c** | Componi |
| **r** | Rispondi |
| **a** | Rispondi a tutti |
| **f** | Inoltra |
| **s** | Stella |
| **e** | Archivia |
| **Shift+I** | Segna come letto |
| **Shift+U** | Segna come non letto |
| **!** | Spam |
| **x** | Seleziona |
| **v** | Sposta |
| **z** | Annulla |
| **#** o **Delete** | Elimina |
| **Escape** | Cancella selezione |
| **p** | Fissa / sblocca messaggio |
| **Ctrl+P** | Stampa messaggio |

## Dentro la conversazione

Quando apri una conversazione con più di un messaggio, le sue schede ricevono scorciatoie da tastiera proprie. Finché la conversazione è aperta in questo modo, **j** / **k** smettono di far scorrere l'elenco dei messaggi e spostano invece un cursore tra le schede, e **r** / **a** / **f** agiscono sulla scheda su cui si trova il cursore, non sul messaggio aperto.

| Scorciatoia | Azione |
|-------------|--------|
| **j** / **k** | Messaggio successivo / precedente nella conversazione |
| **Enter** / **Spazio** | Espandi / comprimi il messaggio selezionato |
| **r** | Rispondi al messaggio selezionato |
| **a** | Rispondi a tutti al messaggio selezionato |
| **f** | Inoltra il messaggio selezionato |
| **Escape** | Esci dalla navigazione nella conversazione (**j** / **k** tornano a far scorrere l'elenco dei messaggi) |

**↑** / **↓** non vengono intercettati qui -- continuano a far scorrere l'elenco dei messaggi anche a conversazione aperta, così puoi sfogliare altre conversazioni senza prima premere **Escape**. Nessuna di queste scorciatoie agisce mentre stai scrivendo in un campo di testo o è aperta una finestra di dialogo.

## IA

| Scorciatoia | Azione |
|-------------|--------|
| **Ctrl+Shift+S** | Riassunto rapido IA |

## Menu contestuale

Fare clic con il tasto destro su qualsiasi messaggio nell'elenco per aprire il menu contestuale. Il menu contestuale fornisce azioni rapide (rispondere, archiviare, spostare e altro) senza aprire il messaggio.

## Generale

| Scorciatoia | Azione |
|-------------|--------|
| **Ctrl+K** | Tavolozza dei comandi (include navigazione a Posticipati, Promemoria, Leggi più tardi e azioni comuni) |
| **?** | Mostra scorciatoie |
