# Keyboard Shortcuts

MailCopilot supports keyboard shortcuts for fast navigation and actions. You can view the shortcut reference at any time by pressing **?** in the application.

The shortcuts below follow the **Gmail** preset (the default). You can switch to the **Outlook** preset in **Settings > Productivity > Hotkeys preset**.

## Navigation

| Shortcut | Action |
|----------|--------|
| **j** / **k** | Next / previous message |
| **o** or **Enter** | Open message |
| **u** | Back to message list |
| **/** | Focus search bar |
| **g** then **i** | Go to Inbox |
| **g** then **s** | Go to Sent |
| **g** then **d** | Go to Drafts |
| **g** then __*__ | Go to Starred |
| **g** then **r** | Go to Read Later |

## Actions

| Shortcut | Action |
|----------|--------|
| **c** | Compose new message |
| **r** | Reply |
| **a** | Reply all |
| **f** | Forward |
| **s** | Star / unstar message |
| **e** | Archive |
| **Shift+I** | Mark as read |
| **Shift+U** | Mark as unread |
| **!** | Mark as spam |
| **x** | Select / deselect message |
| **v** | Move to folder |
| **z** | Undo last action |
| **#** or **Delete** | Delete message |
| **Escape** | Clear selection |
| **p** | Pin / unpin message |
| **Ctrl+P** | Print message |

## Inside a Conversation

When you open a conversation with more than one message, the cards it is made of get their own keyboard shortcuts. While a conversation is open this way, **j** / **k** stop moving the message list and instead move a cursor between its cards, and **r** / **a** / **f** act on whichever card the cursor is on rather than the message you have open.

| Shortcut | Action |
|----------|--------|
| **j** / **k** | Next / previous message in the conversation |
| **Enter** / **Space** | Expand / collapse the focused message |
| **r** | Reply to the focused message |
| **a** | Reply all to the focused message |
| **f** | Forward the focused message |
| **Escape** | Leave conversation navigation (**j** / **k** return to moving the message list) |

**↑** / **↓** are not captured here -- they keep moving the message list even while a conversation is open, so you can browse other conversations without first pressing **Escape**. None of the shortcuts above fire while you are typing in a text field or a dialog is open.

## AI

| Shortcut | Action |
|----------|--------|
| **Ctrl+Shift+S** | Quick AI summarize |

## Context Menu

Right-click any message in the list to open its context menu. The context menu provides quick actions (reply, archive, move, and more) without opening the message.

## General

| Shortcut | Action |
|----------|--------|
| **Ctrl+K** | Open command palette |
| **?** | Show keyboard shortcuts |

## Command Palette

Press **Ctrl+K** to open the command palette. Start typing to search for commands:

- Compose message
- Sync current view
- Focus search
- Open settings
- Go to Inbox / Sent / Drafts / Outbox / Snoozed / Follow-up / Read Later
- Show starred messages
- Go to Unified Inbox
- Enable/disable conversation grouping
- Switch between accounts
- AI actions (Summarize, Reply, New chat, Open panel)
